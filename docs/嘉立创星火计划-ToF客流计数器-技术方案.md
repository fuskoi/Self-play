| 项目 | 内容 |
|------|------|

## 1. 项目背景与痛点

传统客流统计方案存在明显短板：

| 现有方案 | 主要问题 |
|----------|----------|
| 红外对射 | 误差常达 30%～40%，难以区分进出方向，布线复杂 |
| Wi-Fi / 蓝牙探针 | 依赖手机射频开启，无法精确到「人头数」 |

本项目采用 **双阵列 ToF（Time of Flight）深度传感**，结合低功耗 MCU 与 **Wi-Fi / 蓝牙 / 4G** 多模无线传输，实现高精度双向计数、方向识别、在场人数显示与云端/手机汇聚，并满足内置锂电池、无人自动低功耗待机、低电告警等产品化要求。

---

## 2. 项目目标与需求响应

### 2.1 总体目标

设计一款可壁挂、吸顶或安装于门框/走廊的紧凑型客流计数设备，具备：

1. 双阵列 ToF 深度感知，准确识别单人及最多 2～3 人通行（含双人并行、一人随后），计数准确率 **≥ 95%**；
2. 进出双向分别累计，并实时计算当前在场人数；
3. 本地显示与超员蜂鸣告警；
4. Wi-Fi、蓝牙、4G（Cat.1）多通道数据上报至手机端；
5. 内置锂电池供电；无人通行时自动进入低功耗待机；低电量告警提示。

### 2.2 需求逐条响应

| 序号 | 需求要点 | 本方案实现方式 |
|------|----------|----------------|
| 1 | 双阵列 ToF 深度传感器（可辅以微视觉） | **主**：2× VL53L8CX（或 L5CX）；**辅**：1× 低成本灰度摄像头（如 GC0308），仅在多人嫌疑时辅助点数 |
| 2 | 单人/多人通行，准确率 ≥ 95% | ToF 分簇跟踪为主；并行/宽目标时用灰度连通域校验人数；覆盖最多约 3 人 |
| 3 | 双向分别计数、方向判断 | 双 ToF 沿通行方向错位，A→B 为进、B→A 为出（方向仍以 ToF 为准） |
| 4 | 实时显示进/出/在场；超员蜂鸣 | 0.96" OLED + 有源蜂鸣器 + 可配置阈值 |
| 5 | 低功耗 MCU + Wi-Fi / 蓝牙 / 4G | **ESP32-S3-WROOM-1-N8R8**（Wi-Fi+BLE，8MB Flash+8MB PSRAM）+ Cat.1（Air780E / EC800E 类） |
| 6 | 锂电池；无人低功耗待机；低电告警 | 单节锂电 + ADC；分级休眠（关 Wi-Fi/4G，ToF 自主侦测，MCU 浅睡） |
| 7 | 小巧、防尘遮光、快速安装 | 嘉立创 3D/FA 外壳 + IR 透过窗 + 遮光结构 |

### 3.2 设计原则

1. **可实现优先**：器件与算法均按本团队会做完的范围写，不写不做的能力。
2. **需求全覆盖**：ToF 双阵列 + 三网通信 + 低功耗 + 低电告警全部落地。
3. **准确率优先、成本受控**：主方案用双 ToF；为稳冲 ≥95%（2～3 人），**仅增加一颗低成本灰度相机 + 主控升 S3**，增量约 25～35 元；不做深度学习大模型、不存录像。
4. **产品化体验**：分级低功耗（待机关 4G/Wi-Fi/相机）+ 遮光防尘结构。

**为何加相机、仍能压成本：**

| 对比项 | 纯双 ToF | 本方案（ToF + 低成本相机） |
|--------|----------|----------------------------|
| 器件成本 | 约 130～180 元 | 约 **155～210 元**（+25～35 元） |
| 方向识别 | 强 | 同样靠双 ToF |
| 2～3 人并行点数 | 够用但贴身时吃紧 | **贴身并行更稳，利于锁 95%** |
| 实现难度 | 较低 | 中等：灰度缩小图做连通域即可，**不上神经网络** |
| 隐私 | 无图像 | 边缘实时处理，**不存图、不上云传图** |

### 4.2 ToF 双阵列布置

- **安装方式**：门框顶部或走廊天花 **俯视**，高度约 2.0～2.5 m。
- **双传感器间距**：沿通行方向错开 **8～15 cm**。
  - ToF-A：靠近外侧（进门侧）
  - ToF-B：靠近内侧（出门侧）
- **视场覆盖**：8×8 分区覆盖通道宽度；宽通道可通过安装高度与 ROI 标定适配。
- **I²C 连接**：两颗传感器通过 **XSHUT 错峰上电修改从地址**，或分两路 I²C；`INT` 脚开漏上拉后可线或至同一 MCU 唤醒脚。

### 4.3 通信硬件

| 通道 | 硬件载体 | 接口 |
|------|----------|------|
| Wi-Fi | ESP32-S3-WROOM-1-N8R8 内置 | 板载天线 |
| 蓝牙 LE | ESP32-S3-WROOM-1-N8R8 内置 | 板载天线 |
| 4G Cat.1 | 外挂模组 | UART（115200）+ PWRKEY + 电源使能 |

### 4.4 电源与低功耗相关电路

```
锂电池 ──┬── 充电输入（USB）── 充电芯片
         ├── 分压电阻 ── ESP32 ADC（电量/低电）
         ├── 3.3V LDO ── MCU / ToF / OLED
         ├── CAM_PWR_EN（开关）── 相机 3.3V（待机与平时默认关）
         └── LTE_PWR_EN（负载开关）── Cat.1 VBAT（粗线+大电容）
```

**关键设计点：**

1. Cat.1 发射峰值电流可达 1～2 A，**VBAT 必须单独从电池侧供电**，走线加粗，近脚放置 ≥470 µF 电容；禁止与 ESP32 共用弱 LDO。
2. `LTE_PWR_EN`、`CAM_PWR_EN` 待机时切断，降低待机电流。
3. ToF 在待机时保持供电并自主测距，靠 `INT` 唤醒；相机仅多人嫌疑时短暂上电。

### 4.5 结构与工艺

- 外壳：嘉立创 3D 打印或 FA 铝合金外壳申请，体积紧凑，可壁挂/吸顶/门框安装。
- 光学窗：红外透过黑色视窗 + 遮光环，降低环境光与外壳反射串扰。
- 防尘：传感器腔体密封，仅保留必要光窗与散热/天线开孔。
- PCB：优先嘉立创 SMT；板边放置星火计划 LOGO，便于耗材申请合规。

## 5. 软件方案

### 5.1 软件架构

基于 **ESP-IDF + FreeRTOS**，分层如下：

| 层级 | 内容 |
|------|------|
| 驱动层 | VL53L8CX/L5CX ULD、摄像头（DVP/SCCB）、OLED、ADC、蜂鸣器、按键、Cat.1 UART AT |
| 感知层 | ToF 深度分簇跟踪（主）；灰度缩小图连通域人数校验（辅，触发式） |
| 计数层 | 虚拟门线、A→B / B→A 状态机、进出与在场人数 |
| 应用层 | 超员告警、低电告警、本地 UI、参数存储（NVS） |
| 通信层 | BLE GATT、Wi-Fi MQTT、4G AT MQTT（统一 JSON 载荷） |
| 电源层 | ACTIVE / STANDBY；待机关 Wi-Fi/4G/**相机供电** |

### 5.2 任务划分

| 任务 | 职责 |
|------|------|
| `tof_task` | 双传感器测距、分簇与跟踪 |
| `cam_task` | 仅在「多人嫌疑」时上电采 1～数帧灰度，做连通域点数后断电 |
| `count_task` | 融合 ToF 轨迹与相机人数校验，更新进出计数 |
| `ui_task` | OLED 刷新、蜂鸣、按键扫描 |
| `ble_task` | GATT 服务、配网写凭证、实时 Notify |
| `wifi_mqtt_task` | Wi-Fi 连接与 MQTT 发布 |
| `lte_task` | 4G 上电、注网、AT MQTT 状态机 |
| `power_task` | 电量采样、低电逻辑、无人超时进入待机 |

### 5.3 双向计数与并排识别算法

**基本思想：** ToF 负责深度、分簇、方向与轨迹；当出现宽目标/多峰等「多人嫌疑」时，短时打开灰度相机做人数校验，再回到纯 ToF 跟踪。不上云、不存图、不用深度学习。

```
每帧 ToF：
  1. 读 ToF-A / ToF-B 距离矩阵 → 高度滤波 → 横向分簇 → 多目标 track_id
  2. 若簇数≥2 或单簇宽度明显大于单人阈值 → 置 multi_suspect
  3. 若 multi_suspect：CAM 上电 → QQVGA/灰度 → 二值化+连通域 → person_hint(1~3)
     用 person_hint 校正当前过线应计人数；处理完 CAM 断电
  4. 每个 track 穿越虚拟门线：A→B 记进入，B→A 记离开
  5. occupancy = max(0, enter - exit)；超阈值则蜂鸣告警
```

**适用通行形态（承诺范围）：**

- 单人依次；双人并行；前面两人并行、后面再跟随一人；
- 同通道按最多约 3 人设计与测试。

**准确率保障（目标 ≥ 95%）：**

1. 门宽 ≤1.2 m、安装高度约 2.0～2.5 m，空场标定；
2. 多 ID 分别过线 + 防抖；尾随轨迹可延续/再分裂；
3. 贴身并行靠 **触发式灰度点数** 补 ToF 粘连；
4. 测试：单人、双人并行、双人并行+一人随后、快步、折返。

### 5.4 多模通信策略

业务数据统一为 JSON，例如：

```json
{
  "in": 12,
  "out": 9,
  "occ": 3,
  "bat": 76,
  "alarm": 0,
  "ts": 1731384000
}
```

| 通道 | 角色 | 实现要点 |
|------|------|----------|
| 蓝牙 LE | 近场配网、现场看数、设阈值/清零 | GATT 特征值读写 + Notify |
| Wi-Fi | 有路由器时的主上报通道 | ESP-MQTT，主题如 `device/{id}/telemetry` |
| 4G | 无 Wi-Fi 场景兜底 | Cat.1 `AT+MQTTCONN` / `AT+MQTTPUB`，载荷与 Wi-Fi 一致 |

**运行策略（便于演示且省电）：**

1. BLE 在工作模式下可用于配网与近场监控；
2. 已配置 Wi-Fi 则优先 Wi-Fi 上报；
3. Wi-Fi 不可用或用户切换「4G 模式」时启用 Cat.1；
4. 答辩支持一键切换 Wi-Fi / 4G，证明三网能力均具备。

> 说明：需求要求设备「具备」Wi-Fi、蓝牙、4G 能力；待机阶段关闭 Wi-Fi/4G 属于低功耗合规行为，不削弱功能完备性。

### 5.5 人机界面

**OLED 默认界面：**

- 今日进入 / 今日离开 / 当前在场
- 电池电量百分比或电压档位
- 联网状态（BLE / Wi-Fi / 4G）
- 超员、低电等告警图标

**按键（示例）：**

- 短按：切换显示页
- 长按：清零日计数 / 进入配网
- 组合键：Wi-Fi / 4G 模式切换

## 6. 低功耗与电源管理（重点）

### 6.1 需求原文对应

> 内置锂电池供电，无人员通行时自动进入低功耗待机状态，低电量会报警提示。

同时，产品工作续航指标按 **≥ 3 小时**（Wi-Fi 或 4G 工作模式下连续统计与上报）设计。

### 6.2 双模式定义

| 模式 | 场景 | 功耗特征 |
|------|------|----------|
| ACTIVE（工作） | 有人通行或刚检测到人员 | ToF 高频、UI 开启、按策略开启通信；平均约 300～500 mA |
| STANDBY（低功耗待机） | 连续无人超过 T_idle（建议 10～30 s） | 关 Wi-Fi、切断 4G、ToF 自主低频侦测、MCU Light Sleep；目标约 1～5 mA |

**续航估算：**

- 2000 mAh ÷ 500 mA ≈ 4 h → 满足工作模式 ≥ 3 小时（建议选用 2500～3000 mAh 更稳妥）；
- 待机电流 1～5 mA 时，静置可达数百小时，用于体现「无人自动低功耗」。

### 6.3 分级休眠实现路径

```
ACTIVE
  │  连续 T_idle 无有效人体目标
  ▼
enter_standby():
  1. 停止 MQTT 发布与 UI 刷新
  2. 关闭 Wi-Fi；关闭或拉长 BLE
  3. 切断 LTE_PWR_EN（4G 断电）
  4. 切断 CAM_PWR_EN（相机断电）
  5. OLED 熄屏，蜂鸣器关闭
  6. ToF 自主低帧率测距 + 距离阈值中断
  7. GPIO 唤醒：ToF INT、按键 → Light Sleep
  │
  │  ToF INT 或按键唤醒
  ▼
exit_standby():
  1. ToF 恢复高速测距；确认确有目标
  2. 恢复 BLE；按配置恢复 Wi-Fi 或 4G
  3. 相机保持断电，仅多人嫌疑时再上电
  4. OLED 点亮，回到 ACTIVE
```

### 6.4 ToF 唤醒机制

- 使用 ST Ultra Lite Driver 配置自主测距与中断阈值；
- 待机可采用 4×4、约 1 Hz 等级低功耗测距；
- 当中央 ROI 出现类人距离变化时拉低 `INT`；
- 双传感器 `INT` 线或后接入同一 RTC 可唤醒脚。

### 6.5 低电告警

| 阈值（示例，可标定） | 行为 |
|----------------------|------|
| Vbat &lt; 3.50 V | OLED 低电提示 + 短蜂鸣 + BLE/MQTT 上报 `alarm` |
| Vbat &lt; 3.40 V | 禁止开启 4G，优先维持待机与本地告警 |
| Vbat &gt; 3.60 V | 清除低电标志（滞回防抖） |

ADC 采用电阻分压 + 滤波电容；充放电过程注意采样时机，避免充电时误判。

### 6.6 答辩演示建议

1. 串入电流表：有人走动显示数百 mA 工作电流；
2. 人员离开十余秒后进入待机，电流降至 mA 级；
3. 再次进入通道自动唤醒并继续计数；
4. 演示低电提示（调阈值或模拟低压）。

## 10. 风险与对策

| 风险 | 对策 |
|------|------|
| 强光/反光影响 ToF | 遮光罩 + IR 窗；优选 VL53L8CX；室内优先部署 |
| 双人贴身并行或三人挤门漏计 | ToF 分簇标定 + 触发式灰度连通域校正；覆盖双人并行与尾随测试 |
| 4G 峰值拉垮系统 | 独立供电与大电容；待机断电；上电时序保护 |
| Deep Sleep 状态丢失 | 采用 Light Sleep；关键计数写入 NVS |
| 立创缺货 | ToF 在 L8/L5 间互换；Cat.1 在 Air780E/EC800E 间互换 |
| 开发周期紧张 | 手机端用 BLE + 网页/小程序轻量方案；三网共用同一 JSON 载荷 |

## 12. 方案总结

本方案以 **双颗多区 ToF** 做深度与方向主通道，以 **一颗低成本灰度相机** 在多人嫌疑时做人数辅助（触发式上电、不存图），以 **ESP32-S3-WROOM-1-N8R8** 集成 Wi-Fi/蓝牙与轻量图像，以 **Cat.1** 补齐 4G。在单门、最多约 3 人条件下冲击 **≥95%**；分级休眠关 Wi-Fi/4G/相机，ToF 自主侦测唤醒；工作续航 **≥3 小时**。所列模块均为本方案会实现内容，增量硬件控制在约 **25～35 元**。

**优势概括：**

- 需求条目可逐条演示，含微视觉辅助且实现路径明确；
- 准确率有双 ToF + 触发式灰度双重保障，成本仍受控；
- 三网、低功耗、低电告警产品化要点齐全；
- BOM 约 155～210 元，相对纯 ToF 小幅加价换交付把握。

## 附录 C 待机进入伪代码

```c
#define T_IDLE_MS  15000

void power_task(void *arg)
{
    for (;;) {
        if (g_mode == ACTIVE) {
            if (now_ms() - last_detect_ms > T_IDLE_MS)
                enter_standby();
        }
        check_battery_and_alarm();
        vTaskDelay(pdMS_TO_TICKS(200));
    }
}

void enter_standby(void)
{
    wifi_stop();
    ble_stop_or_slow_adv();
    lte_power_cut();      // LTE_PWR_EN = 0
    cam_power_cut();      // CAM_PWR_EN = 0
    oled_off();
    tof_autonomous_irq_mode();

    gpio_wakeup_enable(PIN_TOF_INT, GPIO_INTR_LOW_LEVEL);
    gpio_wakeup_enable(PIN_KEY, GPIO_INTR_LOW_LEVEL);
    esp_sleep_enable_gpio_wakeup();

    g_mode = STANDBY;
    while (g_mode == STANDBY) {
        esp_light_sleep_start();
        if (tof_irq_or_key())
            break;
    }
    exit_standby();
}
```
