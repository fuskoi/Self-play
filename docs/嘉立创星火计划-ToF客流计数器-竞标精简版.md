# 基于双阵列 ToF 的双向客流计数器 · 竞标精简方案

## 硬件

项目采用 ESP32-S3-WROOM-1-N8R8 作为主控，实现设备控制及物联网 Wi-Fi / 蓝牙功能，并预留 USB 程序下载与升级接口；搭载双颗 VL53L5CX 多区 ToF 构成双阵列深度感知，完成通道内单人及最多 3 人（含双人并行、一人随后）的双向进出识别与在场人数统计，计数准确率不低于 95%；辅以一颗 GC0308 灰度摄像头，仅在 ToF 判定多人嫌疑时短时上电做连通域人数校验，辅助判断多人，平时断电；配置 0.96 寸 SSD1306 OLED 实时显示进入、离开、在场人数及电量与联网状态，外加有源蜂鸣器实现超员与低电告警；人机配备 2 个轻触按键，支持清零、配网与 Wi-Fi/4G 模式切换。通信方面，主控集成 Wi-Fi 与 BLE 近场配网及数据推送，同时外挂 Air780E Cat.1 模组经 UART 完成 4G MQTT 上报。电源采用单节 3000 mAh 锂电池，配合 ETA6003 完成锂电池充电与动态路径管理，再经 3.3V Buck-Boost 为系统供电，并通过 ADC 电量采样实现低电提示；Air780E 与 GC0308 电源由独立负载开关控制，无人通行 15 秒后进入待机时可切断，VL53L5CX 保持自主低频侦测并通过中断唤醒主控；外壳防尘遮光，适配门框顶装、吸顶与壁挂安装。

## 软件

项目软件架构基于 ESP-IDF 开发框架，采用 FreeRTOS 实时操作系统进行多任务调度，整体设计遵循分层、模块化原则。软件系统自下而上划分为硬件抽象层、系统服务层、应用功能层与用户交互层。

1. 在硬件抽象层，移植 VL53L5CX 官方测距库，经 I²C 获取 8×8 深度图，并封装 XSHUT、中断脚控制；针对 GC0308 编写触发式灰度采集驱动（上电—采帧—断电），不常开视频流、不存图、不上云传图；驱动 SSD1306 OLED、蜂鸣器、按键、电池 ADC，以及 Air780E 的 UART AT 与电源使能时序；主控侧完成 Wi-Fi / BLE 协议栈初始化。

2. 系统服务层核心聚焦电源管理与连接管理。结合 ETA6003 路径供电与 3.3V Buck-Boost 稳压架构，通过 ADC 监测电量并做低电告警；无人超过 15 秒自动进入低功耗待机：关闭 Wi-Fi、切断 Air780E 与 GC0308 供电，VL53L5CX 转入自主低帧率测距，MCU 进入 Light Sleep，由 ToF 中断或按键唤醒；工作模式下控制测距帧率与 MQTT 上报频率，保证工作续航不低于 3 小时。连接服务统一维护设备状态 JSON，按网络模式经 BLE Notify、Wi-Fi MQTT、4G MQTT 对外发送；参数与日累计计数写入 NVS。

3. 在应用功能层，构建客流业务逻辑中心。对深度图做高度滤波、横向分簇与多目标跟踪，以虚拟门线判定 A→B 进入、B→A 离开，分别累计并计算在场人数；当出现多簇或过宽单簇等多人嫌疑时触发 GC0308 灰度连通域校验，校正并排与贴身场景计数。支持超员阈值告警、低电告警、日计数清零及网络模式切换（Wi-Fi / 4G / 自动）。按键中断作为全局入口，完成界面切换与快捷操作。

4. 用户交互层以 OLED 展示进/出/在场、电量与联网状态；蜂鸣器区分超员与低电提示。近场通过 BLE 完成配网与实时看数；远端通过 MQTT 汇聚至网页看板。不引入重型 UI 框架，不开展云端录像业务。

## 结构

使用 SolidWorks 依据 PCBA、双 VL53L5CX 光窗、GC0308 孔位、OLED、天线、Air780E 与 3000 mAh 电池进行最小化体积设计，形态为门框顶装与吸顶；光学仓遮光防尘，红外透过窗对准 ToF；预留壁挂螺钉安装位。完成 3D 打样分析装配间隙与走线后，通过嘉立创 3D 打印打样验证安装、散热与天线净空。
