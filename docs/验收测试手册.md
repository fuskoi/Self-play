# 烧录后验收测试手册

依据《软件技术方案》**§12 测试用例**与《技术方案》准确率口径执行。  
准确率：`准确率 = 1 - (|设备计数 - 人工真值| / 人工真值)`。

## 0. 前置条件

```bash
idf.py -p COMx flash monitor
```

串口应出现：`ridership boot` → `all tasks started`。

当前固件阶段对应开发里程碑（软件方案 §11）：

| 里程碑 | 能力 | 本手册可测项 |
|--------|------|--------------|
| S1～S2（SIM ToF） | 仿真深度过线、串口计数、OLED 骨架 | T1～T3（仿真）、本地链路 |
| S4～S5 | BLE / 真 MQTT 发布 | T7～T9（驱动补齐后） |
| S6 | 真待机电流 | T6（逻辑可测；电流需表计） |

**串口调试命令**（USB 监视器输入后回车，对齐 §6.1 命令模型）：

| 命令 | 作用 | 对应验收 |
|------|------|----------|
| `help` | 帮助 | — |
| `status` | 打印 telemetry JSON | T7/T8 本地对照 |
| `in [n]` / `out [n]` | 注入进出（默认 1） | T4 链路、UI |
| `clear` | 清零日计数 | 按键/命令清零 |
| `thresh N` | 超员阈值 | T4 |
| `idle N` | 无人待机秒数 | T6 |
| `net wifi\|lte\|auto` | 网络模式 | T10 |
| `standby` | 请求进入 STANDBY | T6 |
| `bat_mv N` | 模拟电池毫伏（0=取消） | T5 |
| `sim on\|off` | ToF 仿真开关 | T1～T3 无传感器 |

---

## T1 单人反复进出 100 次

| 项 | 内容 |
|----|------|
| 条件 | 门宽 ≤1.2 m；安装高 2.0～2.5 m；已空场标定（真机）；或 `sim on` |
| 步骤 | 单人按约定方向进出 100 次；记录人工真值与设备 `in`/`out` |
| 通过 | 综合准确率 ≥ **95%**；OLED/串口 `in/out/occ` 一致 |
| 仿真 | Monitor 观察 SIM 周期过线日志 `count: in=… out=… occ=…` |

## T2 双人并行 50 次

| 项 | 内容 |
|----|------|
| 条件 | 两人并排通行；贴身场景允许触发相机点数（真机） |
| 步骤 | 并行 50 次；分别统计进/出真值 |
| 通过 | 准确率 ≥ 95%；**禁止**「整帧只加 1」漏计并行 |

## T3 双人并行 + 一人随后 50 次

| 项 | 内容 |
|----|------|
| 条件 | 跟距 ≥ **0.4 m** |
| 步骤 | 前两人并行、后一人跟随，共 50 组 |
| 通过 | 准确率 ≥ 95%；多 `track_id` 分别过线 |

## T4 超员告警

| 项 | 内容 |
|----|------|
| 步骤 | `thresh 3` → 多次 `in` 使 `occ≥3`；或真机通行达阈值 |
| 通过 | 蜂鸣模式 A；`status` 中 `"alarm"` **bit0=1**；telemetry 同步置位 |

## T5 低电告警

| 项 | 内容 |
|----|------|
| 步骤 | `bat_mv 3450`（&lt; `V_LOW=3500`）；或硬件模拟低压 |
| 通过 | 蜂鸣模式 B（三短声）；UI/telemetry `"alarm"` **bit1=1**；`bat_mv 0` 取消模拟 |

## T6 无人 15 s 待机

| 项 | 内容 |
|----|------|
| 步骤 | `idle 15`；清空目标后等待；或 `standby` 强制进入 |
| 通过 | 日志 `enter standby`；关 Wi-Fi/4G/相机供电逻辑执行；来人/按键/`TOF_INT` 唤醒后 `exit standby` |
| 注 | 电流下降需万用表；SIM 模式下 `last_detect` 会持续刷新，测自动待机请 `sim off` 或用 `standby` |

## T7 BLE

| 项 | 内容 |
|----|------|
| 步骤 | 手机连 GATT；写 Wi-Fi 凭证；订阅 telemetry Notify |
| 通过 | 配网成功；Notify JSON 与本地 `status` 一致（§6.1 字段） |
| 现状 | NimBLE GATT：服务 `0xFFF0`；`FFF1` Notify、`FFF2` 写 `{"ssid","pass"}`、`FFF3` 命令、`FFF4` 读设备号 |
| 广播名 | `PC-xxxxxx`（MAC 后三字节） |

## T8 Wi-Fi MQTT

| 项 | 内容 |
|----|------|
| Topic | 上报 `device/{id}/telemetry`；下行 `device/{id}/cmd` |
| 步骤 | BLE 写 `FFF2` 配网，或 NVS 预置 `wifi_ssid`/`wifi_pass`；MQTTX 订阅同 topic |
| 通过 | 载荷与本地一致；心跳约 30 s（ACTIVE） |
| 现状 | 等 IP 后连 EMQX，路由层真实 `publish`；待机停 Wi‑Fi |

## T9 4G MQTT

| 项 | 内容 |
|----|------|
| 步骤 | 插卡；`net lte`；注网后 MQTT 上报 |
| 通过 | 载荷与 Wi-Fi **完全相同**；STANDBY 切断蜂窝 |
| 现状 | AT 状态机骨架，待 S5 后勾选 |

## T10 模式切换

| 项 | 内容 |
|----|------|
| 步骤 | `net wifi` / `net lte` / `net auto`；或按键双键组合（§7.2） |
| 通过 | 一键可演示切换；`status` 中 `"net"` 字段变化；路由按 §6.5 互斥 |
