# 客流计数器外壳 · 3D 打印说明

吸顶吊装造型（对应概念图）：天花圆座 + 短颈 + 上下壳。

## 文件位置

```
mechanical/
  stl/
    01_ceiling_base.stl   天花固定圆座
    02_neck.stl           短颈管（中空走线）
    03_shell_upper.stl    上壳（屏/USB/按键侧）
    04_shell_lower.stl    下壳（双 ToF 光窗 + 相机孔）
  generate_enclosure.py   重新生成 STL 的脚本
  scad/enclosure.scad     OpenSCAD 参数化源（可再改尺寸导出）
```

## 主要尺寸（mm）

| 项目 | 数值 |
|------|------|
| 壳体外形 | 约 140 × 78 × 42 |
| 双 ToF 光窗间距 | 100（方案建议 80～150） |
| ToF 光窗孔径 | ⌀15 |
| 相机孔 | ⌀5 |
| 天花座 | ⌀90，厚 4 |
| 颈管 | 外 ⌀28 / 内 ⌀18，高 28 |
| 壁厚 | ≈2.2 |

## 打印建议

- **材料**：PETG 优先（耐热、略韧）；PLA 也可打样
- **层高**：0.2 mm；壁厚 ≥3 圈
- **填充**：15%～25%
- **支撑**：
  - `01` 圆座：平放，一般无需支撑
  - `02` 颈管：竖放
  - `03` 上壳：开口朝上打印，减少支撑
  - `04` 下壳：光窗面朝上或侧打；遮光环可能需支撑
- **公差**：孔位按你打印机收缩微调 ±0.2 mm

## 装配顺序

1. 圆座用 4×M3 胀塞/木螺钉固定到天花  
2. 颈管与圆座中心孔对齐，胶水或螺丝固定；线从中孔穿下  
3. 上壳顶面凸台插入颈管，内部放主控 / 电池 / OLED  
4. 下壳对准 ToF-A / ToF-B / 相机，四角螺丝柱用 M2.5×8～10 与上壳锁紧  
5. ToF 光窗可贴 **红外透过黑色亚克力/遮光片**（方案要求）

## 重新生成

```bash
python mechanical/generate_enclosure.py
```

## 注意

- 当前为 **打样结构件**，未做完整防水；光学窗需另配透红外片。  
- PCB 外形未锁定前，壳内螺丝柱/卡位可能还要改一版。  
- 若要用嘉立创在线 3D / SolidWorks，可用 OpenSCAD 导出 STEP，或按本尺寸重建模。
